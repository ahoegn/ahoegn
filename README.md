### Hi, I'm Aaron Hoegn

Cognitive Science MSc student at the University of Padova. I build computational methods for **multi-block and EEG-behavioral data**: dimensionality reduction, data integration, and Bayesian / MCMC workflows in **R** and **Python** (with CUDA where it pays off).

**Currently working on**
- **Hoegn Parametrization**: a parametrization for multi-block integration, validated on public multiomics data
- A general-purpose pipeline for integrating neuroimaging and behavioral data blocks
